A exportação gera um arquivo ZIP com um arquivo JSON por tabela de dados da sua empresa, mais um arquivo LEIA-ME.txt explicando o conteúdo.

Dados sensíveis, como senhas, tokens e dados de cartão, não são incluídos na exportação. O arquivo contém informações confidenciais da sua empresa: guarde-o em local seguro. A exportação fica disponível mesmo com a assinatura cancelada ou pendente.
